🔍 Ожидаемые результаты:
200 OK - для успешных запросов
201 Created - для создания новых ресурсов
401 Unauthorized - для запросов без токена
403 Forbidden - для запросов с неправильной ролью
404 Not Found - для несуществующих ресурсов
📝 Порядок тестирования:
✅ Запустите приложение: ./mvnw.cmd spring-boot:run
✅ Протестируйте публичные endpoints (поиск комнат)
✅ Получите JWT токен через логин
✅ Протестируйте функции клиента (резервации)
✅ Войдите как админ и протестируйте CRUD операции
✅ Войдите как сотрудник и протестируйте просмотр смен
🚨 Возможные проблемы:
401 Unauthorized - проверьте правильность токена в заголовке Authorization
403 Forbidden - проверьте роль пользователя (CLIENT/ADMIN/EMPLOYE)
500 Internal Server Error - проверьте логи приложения
Все готово для тестирования! 🎉
